# SynapsePro 1.6.0-local：三栏卡片浏览

在 Anki 原生 Browser 中增加可切换的三栏模式：牌组树、原生卡片列表、原生模板预览与编辑标签页。首页 DeckBrowser、复习调度、同步和集合格式没有改造。

## 实现与兼容边界

- `addon/browser_workspace.py` 管理每个 Browser 的布局、搜索、选择和生命周期；通过 Browser hooks 接入，实例级适配在关闭前恢复。
- `addon/browser_preview.py` 继承 Anki Previewer，保留卡片正背面渲染、媒体地址、音频标签和渲染 hooks。控件中没有复习评分动作。
- `addon/browser_scope.py` 通过 Anki SearchNode 构造牌组范围；保留引号、通配符、下划线与反斜线等名称的字面含义。
- 查询使用 Anki QueryOp 的集合任务队列；只保留最新请求，结果回到主线程交给原生表格。表格按需取行与缓存，不预先渲染所有卡片。
- 不迁移牌组，不新建学习数据库。浏览偏好写入本地 profile 的 `synapseproCardBrowser`；原生列与笔记模式在退出三栏时恢复。编辑、删除等显式管理操作仍走 Anki 的原生保存/撤销链。
- 适配依赖部分 Anki 内部控件和表格接口。验证版本为 25.09.4 与 26.08.1；其他版本、第三方浏览器插件与所有自定义模板组合不作兼容承诺。原生预览的输入答案框隐藏行为保留。

## 验收方法

`tests/test_browser_scope.py` 用真实临时集合检查父子牌组、字面名称、OR 搜索范围、空结果和过期请求。插件原有 AI 与功能移除测试同批执行。

`scripts/browser_smoke.py` 在全新 `runtime/<run>` 合成配置中运行真实 Qt 事件循环，检查：

- 默认三栏、父子范围切换、独立正反向卡片、原始模板正背面、图片、样式、原生 mpv 音频播放。
- 原生编辑器实际字段输入，切换牌组自动保存，再回到预览看到更新内容。
- 快速切换搜索、外部条件保留、异步查询期间指定卡片、排序、键盘选择、多选提示、空牌组与空结果。
- 显式删除笔记后对应卡片从列表与预览中消失；标准编辑器、原生侧栏、列设置及笔记模式能够恢复。
- 窄窗口列表/预览切换，关闭重开后的模式与栏宽持久化，大牌组按需取行。

预览的只读检查在显式编辑/删除检查边界之外比较 `revlog` 条数与卡片调度字段摘要，确保浏览与翻面没有产生评分或排程变化。测试使用合成内容、静音 WAV 与简单 SVG，没有访问默认 Anki2 或真实 API 密钥。

`scripts/browser_restart.py` 用第二个 Anki 进程重新打开已通过验收的合成配置，检查本地偏好、集合数据和原生笔记模式持久化。

## 本地验证记录（2026-09-11）

25.09.4 和 26.08.1 各通过 **46 项事件循环检查**及 **7 项独立进程重启检查**。额外验证了关闭嵌入式预览不停止另一原生预览窗口的音频，以及 Esc 正常关闭浏览器。最终合成配置分别为 `runtime/browser-25-release`、`runtime/browser-26-verified`，每份目录中有 `browser-result.json` 和 `browser-restart-result.json`。

25.09.4 的 10 万张卡片查询曾测得约 0.07 秒，表格仅缓存访问过的行。这是本机合成数据的单次结果，不是所有卡片模板、搜索表达式或机器的性能保证。26.08.1 的主流程使用 1 万张性能卡片。

插件单元回归 **13 项通过**，新增文件的 `just addon-lint` 通过，主程序 **`just check` 退出码 0**。完整检查本轮重跑了 629 项 Rust 测试，其他未受影响的检查由构建系统使用有效缓存；没有把缓存命中描述为全部套件重新执行。

SynapsePro 原有功能的事件循环回归 **36 项通过**，其重启回归 **16 项通过**，涵盖 AI 模拟请求、设置、侧栏、计时、实际合成卡片复习和旧数据保留。真实 API 请求与正式学习数据未参与测试。

安装准备和隔离更新脚本会同步 manifest 中声明的版本信息，并保留原 meta.json 的启停、更新开关及配置。Anki 将正数 `max_point_version` 视为已测试版本，因此本包记录 `260801`；它不表示其他版本均已验证。

本轮的最终检查数量、安装包与部署结果以完成报告为准；运行日志、截图及结果 JSON 保留在被 Git 忽略的 `out/`、`runtime/` 下。

已有插件主题注入会在日志中产生一条内联脚本 CSP 警告，Anki 的 MathJax 也有组件版本提示；本次受检的模板样式、图片和正背面渲染成功。两种运行环境均使用独立测试配置，不据此宣称同步服务或所有媒体格式已经验收。

## 更新与恢复

退出 Anki 后，通过既有 `scripts/deploy_test.py manual` 更新隔离安装。该脚本先复制完整配置到 `runtime/backups/`，再替换插件，比较非插件文件哈希；不会安装到默认 Anki2。

仅需恢复界面时，取消勾选“三栏浏览”。恢复插件版本时，退出 Anki，将对应备份中的 `addons21/236979321` 恢复到原位置；保留当前集合、媒体与 profile 数据。只有需要回退测试数据时才恢复整个备份，避免覆盖更新后产生的学习或编辑内容。
