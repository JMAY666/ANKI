# 复习快捷键

## 按键对照

| 操作 | 按键与生效条件 |
| --- | --- |
| 显示答案 | 正面按空格、Enter 或小键盘 Enter |
| 两档：失败 | 答案面按 1，提交原生重来评分 |
| 两档：通过 | 答案面按 2，提交原生良好评分；3／4 不评分 |
| 四档评分 | 答案面默认按 1／2／3／4，对应重来／困难／良好／简单 |
| 下一张 | 明确评分成功后自动进入下一张，没有新增无评分跳过键 |
| 返回牌组 | D 或“结束复习 · 返回牌组”按钮 |
| 撤销 | U 或原生 Ctrl+Z |
| 退出输入／弹窗 | Escape 沿用对应控件原有行为 |

答案面按空格或 Enter 不评分，也不激活获得焦点的评分按钮。填空卡输入答案后，先离开输入框再按显示答案快捷键，或直接点击显示答案按钮。评分按钮仍可鼠标点击。

首选项中的评分键设置用于四档；两档固定使用 1／2。重复、无效、与其他操作冲突或存在序列前缀冲突的评分键不能保存。旧配置中的无效映射不会覆盖其他操作，也不会显示为有效按钮提示；原配置保留供修正。旧“空格或 Enter 也可评分”的存储值保留以便兼容，但不再控制复习行为，界面隐藏该过时开关。

## 输入与页面边界

复习快捷键要求主窗口活动、实际复习页面可见、卡片处于正面或答案面。Qt 文本输入、下拉框、快捷键编辑控件、网页输入、富文本与同源卡片内嵌页面中的输入保留自己的按键；不能检查内容的跨源内嵌页面也不接管快捷键。输入法组合、原生弹窗／菜单和网页模态对话框优先处理自己的输入。

原生快捷键保持关闭自动重复。网页额外阻止空格／Enter 的按钮默认激活，并忽略重复与组合输入事件。异步输入检查和翻面操作绑定发起时的卡片、正反面、页面及评分模式；切页、模式改变或新卡出现后，旧回调不再执行。一次尚未完成的按键请求不会重复排队。

当前／评分配色／高级复习栏共用映射。高级栏的自定义键同时检查主窗口导航、菜单、评分与本组冲突，按钮只提示实际有效的键。学习工作区临时切到统计时移除复习快捷键，恢复当前卡片后重新注册一次。

浏览器预览的翻面、前后卡片和关闭行为仍独立于实际复习，不会写入评分。原生评分、FSRS、撤销、自动前进的独立设置及历史学习记录未改写；两档的按键 2 只是输入映射，实际“通过”评分仍为 3。

## 验证

通过项目配方运行针对性单元与真实界面检查：

```powershell
just review-shortcuts-test
just test-ts
just build
just review-shortcuts-smoke shortcut-check-unique-name
just check
```

真实界面检查只创建 `runtime/` 下标记为合成数据的新账户，禁用同步，覆盖正反面、六种明确评分、失效按键、聚焦按钮、网页／Qt 输入法事件、文本／富文本／内嵌输入、弹窗、长按与页面反复切换。模拟组合输入可验证事件保护，不等于已经逐个验证所有真实输入法的候选窗口。

原程序与资源在更新前备份；程序恢复保留之后的学习记录，不使用旧用户数据库覆盖现有数据。
