# 学习中心与每日 DeepSeek 建议

本功能属于 Anki 内置模块 `qt/aqt/builtin_features/learning/`，与 SynapsePro 和 FSRS Helper 一起运行。界面整合保留原生复习引擎，不引入第二套卡片调度器。

## 入口与使用

- 顶部「学习」、工具 → 学习中心，以及普通「统计」入口打开学习中心。
- 「概览统计」选择账户内的牌组、是否包含子牌组及历史周期。历史周期过滤统计记录，不决定今天的原生队列。
- 「复习」继续使用原来的卡片 WebView、模板、媒体、输入答案、评分、快捷键、编辑与撤销。暂时查看其他页签会保留卡片和正反面，暂停自动翻面/评分并停用隐藏卡片的评分快捷键；返回后恢复原选择。原有答题计时口径不变。
- 「结束本次」展示本次结果并刷新概览。不重复卡片数和评分次数分开；未评分卡片不会生成记录，撤销评分会更新本次结果。
- 「详细统计」嵌入原生图表并保留 PDF 导出。点击图表可浏览对应卡片，也可在原生筛选牌组窗口确认复习其中的到期卡片。
- 全局概览需要先选择牌组开始。父牌组不含子牌组时，使用原生筛选牌组确认范围，避免普通父牌组队列默默包含子牌组。
- 「原牌组概览与工具」保留原概览、困难卡片、词云、自定义学习等操作。
- Shift 点击统计/Shift+T 以及「FSRS 扩展统计（原口径）」保留旧版统计。旧版仍使用月/年/全部历史以及牌组含子牌组的规则，不能把它误认为新的近 7 天或仅本牌组数据。

## 统计口径

概览按 Anki 学习日换日时间计算，查询有效评分（1–4），排除不影响排程的预览练习。跨日真实保留率沿用原生筛选：复习阶段，或上次间隔至少一天；通过为评分大于 1。空样本显示数据不足。统计耗时沿用已保存的原生时间，不额外套用首页组件的 45 秒截断。

新卡、当前积压和未来到期反映当前卡片状态，未来到期不包含每日限额削减；实际队列由 Anki 决定。牌组统计与搜索一样同时考虑筛选牌组中的原牌组关联。原生详细图表与 FSRS 旧扩展继续使用各自口径；不修改旧历史或旧统计公式。

本次结果关联本机成功评分的复习记录 ID，不依靠开始时间之后的全库计数。保留这些关联以便原生撤销、重做之后重新计算，记录位于当前账户的 `LearningWorkspace/history.sqlite`。

## 首次配置和数据发送

每日分析默认关闭、汇总发送默认未授权。打开「分析设置」：

1. 选择一个普通牌组及是否包含子牌组。
2. 设置每日可用分钟数和批准的新卡上限；未设置上限则只观察。
3. 选择「只生成建议」或「确认后应用」。本版本不提供自动应用模式。
4. 复用当前账户已保存的 DeepSeek Key，或输入独立 Key。
5. 阅读汇总范围并勾选允许发送；需要每日运行时同时指定本机执行。

「查看将发送的汇总数据」不会调用 API。发送内容只有日评分次数、不同卡片数、评分及阶段分布、记录耗时、保留率及样本量、当前积压/未来到期、相关参数、目标和最近调整的匿名数值。不发送题面、答案、媒体、真实牌组名称、卡片/牌组 ID 或逐条时间戳。

API 使用 `https://api.deepseek.com/chat/completions`、`deepseek-flash`、非思考模式与 JSON 输出。结构化输出仍需本地校验。Key 不进入报告、集合配置或日志；新学习界面不接收已有完整 Key 回显。

Windows 保存 Key 时，使用当前用户范围的 DPAPI 加密现有 `SynapsePro_Data/ai_secrets.json`，其他聊天服务的键一并保留。已有明文文件仍可读取，在用户保存凭据时转换，不在启动时覆盖。换电脑/系统账户后可能需重新输入。其他平台保留既有聊天存储行为；学习中心独立 Key 加密写入目前仅支持 Windows。

## 每日执行与费用

学习日结束后 10 分钟检查（例如换日在 04:00，则 04:10）；软件未运行时下次打开账户并空闲后补做最近一个完整学习日。分析使用该日、近 7 天及 28 天基线。无学习记录时记录本地状态而不调用 API。

正在复习、同步或后台操作时不启动分析。有同步账户时，每日任务等待本学习日成功同步。安全模式不运行每日任务。全库更新与同步后的助手排程之间留出安静时间。关闭每日开关不会删除已保存的报告。

同一学习日/范围的自动任务只生成一次。临时网络错误最多自动重试两次，每次至少间隔 15 分钟；认证或余额错误等待用户处理。手动重新分析是额外请求，已有应用记录的报告不被覆盖。每次请求单独预留预算；中断时用量未知，保守保留预留值。旧请求晚到不能覆盖新一次请求的结果。

月预算默认 5 元，按本地月份累计，单次预留 0.15 元；单次请求不超过 60,000 字节，输出上限 1,800 tokens。估价按 2026-09-11 Flash 高峰、无缓存价（输入 2 元/百万，输出 8 元/百万）计算，因此不是服务商账单。实际价格变化需要维护单价。典型 5,000 输入+1,000 输出约 0.018 元/次，30 次约 0.54 元；空闲折扣和缓存可能降低费用。

## 应用、观察和恢复

首期只允许提出并确认修改所选牌组的新卡限额，不改共享预设。父级限额仍可能约束子牌组。最多变化 2 张且不超过当前值 10%，至少间隔 7 天，后值不能超过用户批准上限。低于一张的变化不执行。

首次启用后观察 14 天；申请应用至少需要 28 天窗口内 200 条有效记录、50 张不同卡片、14 个有学习记录的日子且启用 FSRS。当前存在「仅今日」新卡覆盖时，不自动猜测应如何处理。报告有效期 24 小时；学习记录、卡片状态、日期或设置变化会使旧建议失效。

期望保留率、学习步骤、最大间隔和 FSRS 权重仅能由模型以文字建议人工检查；原生优化器及模拟接口保持原样。每日任务不调用助手批量推迟、提前、展平、休息或修复评分功能。

应用使用原生配置事务，并保存前后值、理由、来源报告和时间。崩溃恢复只比对当前值，不重复写入。撤销恢复新卡覆盖值（包括恢复继承），不覆盖后续手动修改，不恢复整库，也不抹掉之后发生的学习。

「记录」展示会话、应用和用量，以及同范围的效果观察。未满 14 天或跨日样本不足时不判断效果。达到保留率下降/耗时与积压恶化复核阈值时暂停新建议应用，供用户决定是否撤销；阈值只是保守复核条件，不证明因果或学习能力变化。

## 验证与运行

所有测试使用临时/合成数据，不访问正式账户或真实 API：

```powershell
just learning-check
just builtin-test
just learning-smoke learning-test-001
just learning-smoke learning-test-001 restart
just builtin-smoke joint-test-002
just builtin-smoke joint-test-002 restart
just check
```

`learning-smoke` 验证真实 Anki/Qt 页面、原生统计分子分母、模板及媒体、暂离复习、一次评分一次记录、撤销、本次结果、报告/配置的新进程持久化，以及模拟 API 的确认与撤销路径。网络只在 API 边界替换；真实付费请求和多设备实际同步需单独验收。

源码运行沿用 `just builtin-run`；测试截图和日志位于 Git 排除的 `runtime/` 与 `out/`。正常运行与软件组装方式见 [内置功能说明](../BUILTIN-FEATURES.md)。
