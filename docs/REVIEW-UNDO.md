# 返回上一张卡片

单栏复习左侧中部的「← 上一张卡片」（浮动显示，左侧空隙不足时缩为箭头，双栏保留底部入口）会撤销最近一次评分，并返回该卡片重新作答。原评分产生的调度变化与复习记录由 Anki 原生撤销事务恢复；重新评分只保留更正后的结果。单栏返回问题面，显示答案后重新评分；双栏沿用现有行为，在原评分栏恢复答案面。

- 原生四档、Pass/Fail 两档及高级底栏都有此入口。支持在原生撤销历史仍可用时连续返回。
- 首张卡片尚未评分，或最近操作是编辑、暂停等非评分操作时，按钮置灰，不会跳过或撤销其他操作。需要处理这些操作时使用「编辑 → 撤销」。
- 双栏按两栏共用的实际评分顺序返回，点击任一栏的入口都恢复最近评分的原栏卡片。
- 快速重复点击及已过期的按钮请求不能继续撤销其他记录。评分提交期间不执行返回。
- 原有 `Ctrl+Z`（macOS 为 `Cmd+Z`）与「编辑 → 撤销」保持可用。复习结束已返回牌组页面时，可从该菜单撤销评分，再进入复习；关闭账户后不保证还能撤销此前的评分。

不改变原始笔记、卡片模板或集合结构，不新增学习数据副本。
