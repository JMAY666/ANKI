# 托盘与卡片手写内置功能

两个功能由同一 Anki 26.08.1 初始化，不需要安装独立扩展。固定来源为 AnkiWeb 实际下载包：Minimize to Tray 2，源码头版本 **0.2**；AnkiPenDown，源码版本 **1.1**。完整下载时间、SHA-256、服务器兼容标记及原作者 GPL 许可见 [SOURCE.md](../qt/aqt/builtin_features/desktop_tools/SOURCE.md)。没有新增 Python 或网络依赖。

## 入口与使用

入口：**SynapsePro 左侧快捷栏 → 托盘与手写**，包含启用卡片手写、设置和使用说明。入口位于“快捷开关”下方，点击图标展开菜单，Esc 关闭；原工具菜单中的重复入口已移除。

侧栏调整已通过实际使用目录的 39 项界面与功能验收及 `just check`。此次只更新两个 Python 界面文件和一个 SVG 图标，不迁移用户数据。更新前文件保存在 `runtime/desktop-sidebar-update/original/`；关闭 Anki 后执行 `pwsh -NoProfile -File ./runtime/desktop-sidebar-update/rollback.ps1` 可恢复原入口位置。

- 托盘：按用户确认，默认关闭“关闭时收起到托盘”，点击 × 正常退出。开启后点击 × 隐藏当前可见窗口，点击托盘图标恢复；文件 → 退出始终正常关闭集合并退出。系统托盘不可用时不会隐藏窗口。保留启动隐藏和诊断日志开关；禁用托盘时先恢复隐藏窗口。
- 手写：保留两支可分别设置颜色的画笔、荧光笔、整条笔画橡皮、撤销／重做、可撤销清空、隐藏／显示、大／小画布、跟随滚动、工具栏四角位置、边距、横纵排列、紧凑模式、绘画时隐藏工具栏／指针、专注模式、画笔粗细及带透明度的画布背景。
- Ctrl+R 在复习页切换手写；Alt+Z 撤销笔画，Alt+Y 重做，句点清空，逗号隐藏／显示，Alt+B 切换大／小画布。输入文字、输入法组合及非复习页面不处理绘画快捷键。隐藏笔迹后可操作卡片输入框和链接。
- 笔迹是当前卡片的临时草稿：翻面保留，下一张清空；不写入卡片、模板、媒体或学习记录，也不在重启后保存。配置会保存，关闭／重新开启手写会新建画布。专注模式隐藏工具栏后，可从本设置页关闭。

## 本地化与兼容

新增菜单、设置、颜色对话框标题、按钮提示、错误说明及帮助接入当前语言选择，简体中文下使用中文，非中文下保留英语。画布控件同时提供中文文字提示和无障碍标签；设置页支持换行和滚动。配置键、用户内容、颜色值、作者名称不翻译。

AnkiPenDown 继续读取和保存账户偏好中的原 `ts_*` 键。缺失字段逐项使用默认值，不因缺少一个字段重置其他旧配置；无效值保留原件并停止启用，不把未经校验的字符串插入页面。其他账户字段保持不变。托盘配置位于数据根目录的 `builtin_features/minimize_to_tray.json`，首次复制旧扩展配置和未知字段，之后以内置配置为准，原件不删除。发现不同的旧副本配置时拒绝混合覆盖。

原扩展 ID `85158043`、`812527193` 及声明相同 manifest package 的改名副本沿用现有旧扩展过滤机制，内置初始化成功后不重复加载。

手写原包的设置操作会重新进入复习，当前适配改为仅更新画布，保留当前卡片、正反面、评分记录及已绘笔迹。渲染逻辑在独立作用域内运行，挂载时移除旧监听和绘制循环，离开复习时清理画布。托盘通过主程序关闭入口接入，不替换主窗口方法，也不修改 Qt 全局最后窗口退出策略。原复习布局、Pass/Fail、三栏浏览、音频可见确认和六项复习工具保留。
