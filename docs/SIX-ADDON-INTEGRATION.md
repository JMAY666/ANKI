## 已确认的冲突处理

1. **评分按钮覆盖**：Advanced 原代码直接替换 Reviewer 的按钮列表与渲染方法，会绕开现有 Pass/Fail；Button Colours 又对相同文字着色。按用户确认，保留当前默认外观，提供当前／评分配色／高级复习栏三种样式；所有样式经过当前原生评分流程。Pass/Fail 控制两档语义、自定义名称及文字颜色，并具有优先级。只重建底栏，不重载卡片页面、重置计时或变更当前卡片。
2. **双重评分提示**：Advanced Tooltip 与顶部标签原本会在同一次评分同时出现。按用户确认，合并为关闭／顶部标签／浮动评分提示的单选模式，默认关闭。两种提示能力保留，只在成功评分后显示一份反馈。
3. **跳过与调度**：原插件在当前调度器中将“Next Card”解释为搁置。保留搁置／暂停／恢复本次跳过，按钮默认隐藏；恢复只针对本次工具操作且队列仍匹配的卡片。退出复习或关闭账户会恢复本工具的手动搁置，暂停保留到手动恢复。不会全库解除再重新搁置。原生撤销仍可用。
4. **主页与底栏覆盖**：按用户确认保留现有主页和已移除入口；原附加统计进入现有统计区。独立插件菜单位置、主页按钮样式及其他独立插件的兼容标记保留在旧配置数据中，由主程序接管对应职责，不恢复旧页面。
5. **技术兼容修复**：扩展统计使用单次页面绑定、有命名空间的接口、整数 ID 校验和参数化 SQL；集合访问切回主线程。初始统计请求显式使用当前页面范围，修复未初始化请求及旧前端拒绝占位 Promise。页面离开时取消请求，账户切换使旧请求令牌失效。
6. **事件与快捷键**：初始化和原插件拦截沿用既有统一入口。六个 ID 及其已声明的 manifest package 副本不会重复加载；保留原外部插件加载边界。样式更新先清理旧复习快捷键再注册。Advanced 配置保存会检查与原生评分／复习快捷键及本组快捷键的重复。

Pace 与原生复习记录的计时口径不同：Pace 测量问题显示至翻面，排除暂停／非活动窗口时间；Confident But Wrong 使用原生记录的耗时。它们各自保留原算法，不把两个时间混成一个分值。

## 配置与恢复基线

设置保存到本机 Anki 数据根目录的 `builtin_features/review_tools/`，每项独立 JSON，沿用此前内置配置方式。首次从原插件的 `config.json` 与 `meta.json.config` 复制合并，后者优先；未知字段与 `user_files` 保留，来源不修改。原非重叠功能的停用状态保留。已存在的内置配置不反复迁入；损坏 JSON 或不同的旧副本配置会明确报错，不以默认值覆盖原件。

Advanced 的原预设保存在软件资源中的 `advanced/presets/`，可通过原生设置的导入功能载入。导入先预览，保存才生效；可导出本机工具设置。Search Stats 的自定义翻译存放在可写的数据目录，不写安装目录。

修改前恢复基线：`runtime/six-addons-20260911/`，对应提交 `94f410e50`，包含源码 ZIP、原程序 4,919 个文件、正式数据 12,924 个文件及 SHA-256 清单。原始下载包也保留在该目录。全部备份、合成配置、日志和完整程序沿用现有 Git 排除规则。

本次软件包及实际安装仍更新 `dist/Anki-learning-workspace-26.8.1/Anki.exe`。安装器保留替换前目录并写入恢复记录。恢复程序、保留之后学习数据的命令：
